```mermaid
sequenceDiagram
  autonumber
  actor U as ユーザー
  participant MA as MainActivity
  participant PM as PackageManager
  participant EN as CategorizationEngine
  participant FB as FallbackAppCategorizer
  participant RB as RuleBasedAppCategorizer
  participant BC as BedrockAppCategorizer
  participant CP as CognitoCredentialsProvider
  participant IS as IdentityIdStore (SharedPreferences)
  participant CG as Cognito Identity Pool
  participant GW as API Gateway
  participant LM as categorizer Lambda
  participant DB as DynamoDB rate-limit
  participant BR as Bedrock
  participant RM as Room app_categories
  Note over MA,RM: 接続値 (API URL / Identity Pool ID) が未設定のビルドでは FallbackAppCategorizer / BedrockAppCategorizer を使わず RuleBased のみで分類する
  U->>MA: Scan ボタン
  MA->>PM: queryIntentActivities (ランチャー表示アプリを全件)
  PM-->>MA: InstalledApp 一覧 (未分類に限らず全件)
  MA->>FB: reset() (フォールバック件数・理由をクリア)
  MA->>EN: categorizeInBatches (batchSize=50)
  loop 50 件ごとのバッチ
    EN->>FB: categorize(batch)
    FB->>BC: categorize(batch) を runCatching で実行
    BC->>CP: get()
    opt メモリ上の資格情報なし または 失効 60 秒前
      CP->>IS: load(poolId)
      IS-->>CP: 保存済み identityId (Pool ID 不一致なら null)
      alt 保存 ID あり
        CP->>CG: GetCredentialsForIdentity (保存 ID)
        opt ResourceNotFound / NotAuthorized (保存 ID が無効)
          CP->>IS: clear()
          CP->>CG: GetId (1 回だけ取り直す)
          CG-->>CP: 新しい identityId
          CP->>IS: save(poolId, identityId)
          CP->>CG: GetCredentialsForIdentity (新 ID)
        end
      else 保存 ID なし (初回)
        CP->>CG: GetId
        CG-->>CP: identityId (未認証)
        CP->>IS: save(poolId, identityId)
        CP->>CG: GetCredentialsForIdentity
      end
      CG-->>CP: 短期クレデンシャル (unauth ロール)
    end
    CP-->>BC: 資格情報
    BC->>BC: SigV4Signer で署名 (service=execute-api)
    BC->>GW: POST /categorize (HTTPS + SigV4)
    Note over GW,LM: AWS_IAM 認可 / JSON Schema 検証 (1-50 件, 文字長上限) / ステージスロットル
    GW->>LM: AWS_PROXY (cognitoIdentityId 付き)
    Note over LM,DB: 入力検証 64KB上限 / 件数 / 各項目トリム+切詰め → 違反は 400, identity 無しは 401
    LM->>DB: TransactWriteItems (SWITCH/GLOBAL 確認 + ID# 日次 + ID# 月次 + GLOBAL/DAY# 加算)
    Note over LM,DB: TransactionConflict なら 50-200ms 待って 1 回だけ再試行 (以下は再試行後の結果)
    alt kill switch ON
      DB-->>LM: TransactionCanceled [0] (kill switch)
      LM-->>GW: 503 reason=budget limit reached
    else identity 日次 / 月次 / 全体日次 の上限超過
      DB-->>LM: TransactionCanceled [1] / [2] / [3]
      LM-->>GW: 429 rate limit exceeded (scope=daily / monthly / global)
    else 衝突が解けない / その他
      DB-->>LM: TransactionCanceled (TransactionConflict 等)
      LM-->>GW: 503 busy (reason=conflict / unknown)
    else 許可 (4 件とも原子的に成立)
      LM->>BR: Converse (Haiku 4.5, jp 推論プロファイル, temperature 0)
      BR-->>LM: カテゴリ JSON
      Note over LM,DB: パース不能・候補外カテゴリは Other に丸める (Bedrock 例外時は 502)
      LM-->>GW: 200 results (source=bedrock)
    end
    GW-->>BC: HTTP レスポンス
    alt 200
      BC-->>FB: CategorizedApp (source=bedrock)
    else 429 / 503 / その他 非200 / 通信・Cognito 失敗
      BC-->>FB: 例外 (429→RateLimitException / 503 予算停止→KillSwitchException / 他→RuntimeException)
      Note over FB,CP: fallbackCount += バッチ件数 / lastReason: monthly→月次上限, daily・global→日次上限, KillSwitch→停止中, 他→通信エラー
      FB->>RB: categorize(batch)
      RB-->>FB: キーワード規則で分類 (source=offline-rules)
    end
    FB-->>EN: CategorizedApp
    EN-->>MA: 進捗コールバック
  end
  EN-->>MA: 全バッチの結果 (カテゴリ順に整列)
  MA->>RM: saveApps (locked=手動変更済みの行は上書きしない)
  MA->>FB: fallbackCount / lastReason を読取
  MA->>MA: 完了メッセージ (フォールバック件数と理由) + 一覧描画 + ウィジェット更新
```

補足: フォールバックは `FallbackAppCategorizer` が `runCatching` で行い、失敗理由で分岐せず BedrockAppCategorizer 側で投げられた例外すべてが対象です（理由は件数と共に記録するだけ）。全体日次上限 (scope=global) は利用者向け表示では日次上限扱いです。
